# Gotto Jobs Online – Website Clone

This project is a frontend clone of the "Gotto Jobs Online" website, created using **HTML** and **CSS**.  
The purpose of this project is to practice website layout, styling, and responsive design using core web technologies.

## 🚀 Features
- Clean and modern UI
- Structured job listing sections
- Pure HTML & CSS (no frameworks)

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📂 Project Purpose
This project was built for:
- Improving frontend development skills
- Practicing CSS layouts
- Understanding real-world website structure
